# OG card fonts

`Geist-Regular.ttf` and `Geist-SemiBold.ttf` are used by `scripts/og-image.mjs`
to render project OpenGraph card images at build time (matching the site's
Geist typeface). They are committed so the build needs no network access.

**Geist** is © 2023 Vercel, licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). Files here are the Latin subsets served by Google
Fonts (https://fonts.google.com/specimen/Geist).
